# Decisions
One API and role-selectable worker package avoid decorative microservices. PostgreSQL serialization protects aggregate quotas across resources; partial unique reservations prevent conflicting execution. External effects are modeled separately so the effect/ledger crash boundary is real. Kafka transports durable action identifiers; payloads remain authoritative in PostgreSQL. Redis availability does not affect correctness. External simulator state shares a database server but uses separate transactions; future external adapters need their own reconciliation contracts.
