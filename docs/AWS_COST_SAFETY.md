# AWS safety
Default local development costs $0 in AWS services. No AWS calls or infrastructure are implemented. Example cloud variables document future guardrails; they are not account spending caps. Do not add live behavior merely because environment variables are set.
Before any optional deployment obtain explicit approval for specific resources and operations, region, current price estimates, instance type, runtime, resource allowlist, expiration tags and teardown plan. Avoid EKS/MSK/RDS/NAT gateways and always-on load balancers. A possible $10?$20 demonstration budget is a proposal, not authorization. Use SDK credential chain and least privilege; never log credentials. Budgets alerts are delayed and do not enforce a spending cap. No cloud cleanup script is supplied because no cloud resources can be created by this project.
